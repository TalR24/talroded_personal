## Writing archive

`writing/index.html` lists every NYCuriosity post as an `archive-item` row inside `<div class="archive-list" id="archive">`. The filter tabs are All, State Capacity, Infrastructure & Streets, Policy & Economics, Civic Tech, Community Board and Parks. Each row carries a `data-cat` token (several tokens are allowed). Categories mirror the post's Substack tags.

New posts arrive through `scripts/sync_posts.py` (below). All Substack links use `https://www.nycuriosity.com`, never `nycuriosity.substack.com`.

## SEO and LLM files

`sitemap.xml`, `llms.txt` and the JSON-LD block on the homepage (schema.org Person) are generated by scripts in the data site repo, not edited by hand. From `data_website/`:

```
python3 seo/build_sitemap.py --site personal
```

This regenerates the sitemap, `llms.txt` and the JSON-LD together. Run it after adding or renaming a page. `robots.txt` explicitly allows AI crawlers (GPTBot, ClaudeBot, PerplexityBot, Google-Extended, and others) and points to `/llms.txt`. Every page carries title, description, canonical and og tags (the `seo` skill and data site hooks enforce this).

## Copy currency

`profile_facts.json` is the single source of truth for every public fact about Tal (its `_about` field says so): identity, descriptor, roles, bylines, press, talks, live numbers, banned strings and the list of copy surfaces. Change a fact there first.

`scripts/copy_check.py` compares the site against it:

1. Refreshes live numbers (fiscal records, obligations, laws, State Capacity orgs) and rewrites every embedded number listed in `embedded_numbers` (for example the "View all 74 posts" link). These fixes are mechanical.
2. Reconciles post counts through `sync_posts.py` (skipped with `--ci`, because Substack blocks GitHub Actions IPs).
3. Scans pages for banned strings, stale descriptors and em dashes. These are reported for a human, never auto-fixed.
4. Writes `copy_reports/copy_check_YYYY-MM-DD.md` and `copy_reports/latest.md`.

Flags: `--ci`, `--strict` (exit 1 on prose flags), `--no-write` (report only).

## Automation

| Workflow | Schedule | What it does |
|---|---|---|
| `copy_check.yml` | Mondays 13:17 UTC (`17 13 * * 1`), plus manual dispatch | Runs `copy_check.py --ci`, commits number fixes and reports, opens or comments on a `copy-check` issue when `latest.md` has items needing a human |
| `sync_posts.yml` | Manual dispatch only | Runs `sync_posts.py` and commits `writing/index.html`. Substack blocks CI IPs, so the sync runs locally |

The monthly "Copy currency review" Claude routine (4th of each month) emails proposed copy edits for this and other sites. It is an input to `profile_facts.json` changes, not a workflow in this repo.

## Common commands

```
python3 scripts/sync_posts.py              # add new Substack posts to writing/index.html
python3 scripts/copy_check.py              # full local copy check
python3 scripts/copy_check.py --no-write   # report only
cd ../data_website && python3 seo/build_sitemap.py --site personal   # sitemap + llms.txt + JSON-LD
```

`sync_posts.py` reads the public Substack archive endpoint, which returns only a subset of posts, so it is safe only for inserting new posts at the top of the list. Never use it to count or regenerate the archive. After it runs, `git diff --name-only` should show `writing/index.html`; commit that path and push.

## Site chrome and conventions

- Header and footer markup is duplicated per page; all styling lives in `assets/style.css`. For a new page, copy the header and footer from an existing page.
- Header: dark bar with brand (`tal·roded`), nav (Writing, Publications & Press, Wiki, About, Services), then a `.header-right` row of outlined `.header-icon-link` links (Data, Support my work) and the white `.header-cta` (`NYCuriosity ↗`).
- Footer: `.footer-inner` with brand, `.footer-links` nav, social icons (Substack, LinkedIn, X, Instagram, TikTok, GitHub), the `.footer-support` pill and copyright.
- Support button: label "Support my work", coffee-cup icon, links to `https://buymeacoffee.com/nycuriosity`, `target="_blank"`. Header class `header-icon-link header-support`, footer class `footer-support`.
- Link previews: shell pages carry `og:image` and `twitter:card` meta pointing at `/og_card.png`. Regenerate the card by screenshotting an HTML mock at 1200×630 with headless Chrome.
- Canonical NYCuriosity descriptor, verbatim wherever the newsletter is described (from `descriptor.nycuriosity` in `profile_facts.json`): "data-driven analysis of NYC transit, streets, the City budget, and how the city governs itself."
- Block Party appears as a project card in page bodies, not in the header.
- `resume_oti_business_analysis.html` has no header or footer, is gitignored and is not deployed; skip it when propagating chrome.
- Copy follows the voice rules in the workspace CLAUDE.md: no em dashes or double hyphens in prose, no weasel words, exact numbers.
